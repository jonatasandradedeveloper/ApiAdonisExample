O objetivo é ter **uma referência única** para produto, design, engenharia e operação:

1. O **Hub** chama as APIs dos autorizadores.
2. App e site **não** falam com Interplayers, Funcional ou ePharma — falam só com o Hub.
3. A “autorização” do PBM é **autorização de negócio** (código/transação de desconto), não um token de API para o canal usar depois.
4. O canal pede → o Hub orquestra → o autorizador decide elegibilidade, limite e gera a autorização → o Hub devolve o resultado para a tela.
