**O que o MobiliAuto é:** super app de assistência automotiva sob demanda (guincho, chaveiro, mecânico, borracheiro e motorista de resgate/substituto).

**O que o MobiliAuto não é:** classificado de compra e venda de carros, remoção hospitalar nem hospedagem.
