# URGENTE — Year-End / December Cycle · prazo 28/08 (sexta)

**Até sexta-feira, 28/08/2026:** cada profissional deve fazer a **autoavaliação no Workday**, na aba **ABCD Reflections** (também chamada de reflexão / Save and Reflect).

Fonte: guia oficial de prioridades no Workday + recado do ciclo.

## O que a empresa exige (FY26)

Todo mundo deve ter **uma prioridade em cada categoria**:

1. **Criação de Valor para o Cliente**
2. **Habilitação de IA**
3. **Ótimo Lugar para Trabalhar para Reinventores**
4. **Comunidade**

Se a prioridade ainda estiver na categoria antiga (FY25), **edite e remapeie** para uma das quatro acima.

## Caminho no Workday (passo a passo curto)

1. Abrir o Workday.
2. Ícone da persona (canto superior direito) → **View Profile**.
3. Menu lateral → **Performance** → **Priorities HomePage**.
4. Conferir / criar / editar as 4 prioridades (uma por categoria).
5. Em cada prioridade: Título, Descrição, Categoria, até 3 métricas, até 2 revisores (Enterprise ID), Conta do Cliente (se aplicável), Status.
6. **Salvar e Refletir** / **Iniciar a Reflexão** (ABCD Reflections).
7. Em cada reflexão: o que deu certo, o que melhorar, impacto 0–10, métricas Atual vs Alvo.
8. **Enviar** (não deixar só em rascunho).
9. Solicitar reflexão do revisor, se pedido pelo fluxo.

## Revisores

Formato: **Enterprise ID** (o que vem antes de `@avanade.com` / `@accenture.com`).  
Até **2** por prioridade — normalmente líder de projeto / gerente.
